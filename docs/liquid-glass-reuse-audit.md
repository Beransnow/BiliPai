# 液态玻璃复用评估（2026-09-05）

## 基线与结论

依赖基线为 `gradle/libs.versions.toml` 的 Miuix `0.9.4-4f86de92-SNAPSHOT`。
交互参考本地 Miuix checkout `b09d5deb` 的
`example/shared/src/commonMain/kotlin/component/liquid/LiquidGlassNavigationBar.kt`
与 `component/animation/DampedDragAnimation.kt`；后者最近修改为 `6cef2957`。
参考仓库：https://github.com/compose-miuix-ui/miuix 。示例基线与依赖版本并不等同。

项目复用了 Miuix Backdrop/blur 基础设施，并移植、适配了示例的透镜和交互。
这不是直接调用一个完整上游导航组件，因此不以百分比宣称“完整复用”。

## 能力对照

| 层 | 已有能力 | 本次处理与边界 |
| --- | --- | --- |
| 背景效果 | Miuix Backdrop、blur；本地 Lens、Vibrancy、CombinedBackdrop、InnerShadow | 保留底栏组合捕获与背景自采样保护，无依赖升级 |
| 交互 | 按压弹簧、移动、拖动、Pager 跟随、高光 | 修复 press/release 共用任务导致点按放大被取消；释放在接近目标且按压完成后回缩 |
| 本地适配 | 同步拖动目标、最新任务优先、Pager 所有权、搜索宽度补偿 | 保留，不能直接用上游示例覆盖这些逻辑 |
| 形状 | 胶囊形状、底栏指示器几何 | 上游也用 CircleShape；扁平感取决于宽高比。非底栏接入已有 1.6 比例策略，底栏规则不变 |
| 内容 | 底栏选中内容捕获、横向形变补偿 | 分段控件内容改为独立前景，完整内容高度不受扁平透镜掩码限制；按压等比缩放，图标切换开关透传 |
| 语义与触控 | 主内容提供 Tab 语义；装饰层清除语义 | 分段控件请求至少 48dp 高度与固定槽宽；父级强约束及过多等宽项仍需设备检查 |

分段控件的独立前景是有意的可读性适配：背景仍有液态透镜与高光，文字与图标
不再进入指示器的折射采样。这样背景可变扁而文字不会被裁切或横向拉伸，并省去该路径的选中内容捕获层。
底栏的内容折射和反向缩放保持不变。

## 尚未完整消费的封装参数

- `BottomBarLiquidSegmentedControl.tapPressRefractionEnabled` 未传入浮动控件路径。
- `indicatorIdleSurfaceColorOverride` 未传入浮动控件路径。
- `containerVerticalPadding` 被传递，但浮动包装仍采用底层固定内边距；水平内边距参与外部宽度计算，底层槽位仍使用 4dp。
- 缺少完整的图形效果、字体放大和跨设备回归证据；源码接线不能替代渲染验证。

后续优先清理以上接口契约：先核对调用者期望，再使参数实际生效或明确弃用。
不要一次性移植上游全部示例，也不要把底栏与分段控件的内容几何强制统一。
性能优化优先保持绘制阶段读取动画值、复用外部背景源及避免重复捕获；进一步性能结论需真实设备数据。
