# 液态玻璃复用评估（2026-09-05）

## 基线与结论

依赖基线为 `gradle/libs.versions.toml` 的 Miuix `0.9.4-4f86de92-SNAPSHOT`。
交互参考本地 Miuix checkout `b09d5deb` 的
`example/shared/src/commonMain/kotlin/component/liquid/LiquidGlassNavigationBar.kt`
与 `component/animation/DampedDragAnimation.kt`；后者最近修改为 `6cef2957`。
参考仓库：https://github.com/compose-miuix-ui/miuix 。示例基线与依赖版本并不等同。

项目复用了 Miuix Backdrop/blur 基础设施，并移植、适配了示例的透镜和交互。
这不是直接调用一个完整上游导航组件，因此不以百分比宣称“完整复用”。

## 能力对照

| 层 | 已有能力 | 本次处理与边界 |
| --- | --- | --- |
| 背景效果 | Miuix Backdrop、blur；本地 Lens、Vibrancy、CombinedBackdrop、InnerShadow | 保留底栏组合捕获与背景自采样保护，无依赖升级 |
| 交互 | 按压弹簧、移动、拖动、Pager 跟随、高光 | 修复 press/release 共用任务导致点按放大被取消；释放在接近目标且按压完成后回缩 |
| 本地适配 | 同步拖动目标、最新任务优先、Pager 所有权、搜索宽度补偿 | 保留，不能直接用上游示例覆盖这些逻辑 |
| 形状 | 胶囊形状、底栏指示器几何 | 上游也用 CircleShape；扁平感取决于宽高比。非底栏接入已有 1.6 比例策略，底栏规则不变 |
| 内容 | 底栏选中内容捕获、横向形变补偿 | 分段控件内容改为独立前景，完整内容高度不受扁平透镜掩码限制；按压等比缩放，图标切换开关透传 |
| 语义与触控 | 主内容提供 Tab 语义；装饰层清除语义 | 分段控件请求至少 48dp 高度与固定槽宽；父级强约束及过多等宽项仍需设备检查 |

分段控件的独立前景是有意的可读性适配：背景仍有液态透镜与高光，文字与图标
不再进入指示器的折射采样。这样背景可变扁而文字不会被裁切或横向拉伸，并省去该路径的选中内容捕获层。
底栏的内容折射和反向缩放保持不变。

## 封装参数消费（已补齐）

对齐基准为首页底栏共用的 `FloatingBottomBar` 渲染实现。默认参数为水平/垂直内边距
4dp、点按折射开启、闲置指示器颜色不覆盖；不为分段控件复制一套材质常量或弹簧。

| 参数 | 实际消费与默认行为 |
| --- | --- |
| `tapPressRefractionEnabled` | 入口、包装、共用渲染器全链路透传。默认采用底栏按压进度驱动透镜；false 只关闭点按引起的指示器折射，保留缩放、高光和拖动/Pager 折射 |
| `indicatorIdleSurfaceColorOverride` | 玻璃路径覆盖闲置表面颜色，仍按底栏的 `1 - pressProgress` 淡出；无玻璃路径覆盖选中背景。不传值时分别沿用底栏深浅色闲置表面与普通选中色 |
| `containerHorizontalPadding` | 外部宽度、受约束后的实际槽宽、指示器偏移、捕获/前景内容和 LTR/RTL 手势命中使用同一个值；不再固定减去 8dp。负值归零 |
| `containerVerticalPadding` | 消费到共用壳层内容与分段前景层布局，范围为 0 到壳高的一半；不把文字压缩成扁平指示器的高度 |
| `liquidGlassTuningOverride` / 颜色覆盖 | 继续通过共用渲染器消费。未覆盖时使用存储的玻璃强度、进阶设置与可读性策略 |

`allowNativeLabelOverflow`、`preferInlineContentStyle`、`forceEqualWidth` 是原生布局/样式选择契约，
不是玻璃材质参数；浮动分段路径本身采用等宽槽位。`enabled` 与拖动开关仍控制选择回调及手势。
首页顶部直接使用包装层时也采用相同默认值。

保留上一轮批准的非底栏 1.6 几何与独立内容前景：材质和交互共用底栏实现，
但内容不经过底栏的捕获折射，因此不能宣称两个路径逐像素相同。
缺少完整的图形效果、字体放大和跨设备回归证据；源码接线不能替代渲染验证。

不要一次性移植上游全部示例，也不要把底栏与分段控件的内容几何强制统一。
性能优化优先保持绘制阶段读取动画值、复用外部背景源及避免重复捕获；进一步性能结论需真实设备数据。

## 本次验证边界

新增可控 Compose 帧时钟测试，覆盖点按放大及复原、快速反向切换与拖动释放、单项同目标释放；
新增分段指示器比例与首尾边界测试，并保留底栏默认几何断言。
参数补齐新增点按折射开关/拖动/Pager 组合、非默认内边距槽位与首尾对齐测试，以及透传集成断言。
这些测试尚未执行：用户要求本轮不编译、不运行 Gradle 测试、不打包。
本轮仅进行差异和源码静态检查，未进行设备验收。

后续授权后的设备验收：动态分页、视频详情分页与评论排序、首页顶部和底栏；
手机/平板、深浅色、字体放大、图文模式、玻璃/图标动画/搜索开关；
连续点按、滑动中点按、拖动取消、返回页面和前后台恢复。检查缩放复原、文字无裁切、
指示器不越界及不重复提交选择。
